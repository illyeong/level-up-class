StudioNAP SpriteFont
===================

Description
-----------
StudioNAP SpriteFont is an editor extension tool that allows you to easily create and manage sprite fonts in Unity.

Key Features
-----------
1. Sprite Font Prefab Creation
   - Select "StudioNAP/SpriteFont" from the GameObject menu
   - Automatically placed as a child of the currently selected GameObject
   - Created at the current Scene view position

How to Use
----------
1. Select GameObject > StudioNAP > SpriteFont from the Unity Editor's top menu.
2. The SNFont prefab will be automatically created and placed as a child of the currently selected GameObject.
3. Select the created SNFont object to adjust font settings in the Inspector window.
4. To change font, replace Sprite Atlas in Sprite Font component.
5. You can always change the text image files with your own.

System Requirements
-----------------
- Unity 2019.4 or higher
- Universal Render Pipeline (URP) support

Important Notes
-------------
- The SNFont prefab must be located in the Resources/Prefab/StudioNAP folder.
- Scene changes are automatically saved.
